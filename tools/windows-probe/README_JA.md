# Windowsでの4作品メタデータ診断

Edge／Chromeで、利用者が指定した4作品のページ数・小説記法・挿絵・うごイラのフレーム情報を確認する診断用拡張です。レポートにはCookie、パスワード、リクエストヘッダー、小説本文を含めません。本文はUTF-8のバイト数とSHA-256のみを記録します。媒体URLのクエリ値も除きます。

## 使い方

1. ZIPをWindows上で展開します。
2. Edgeの `edge://extensions`、またはChromeの `chrome://extensions` を開きます。「開発者モード」をオンにし、「展開して読み込み」で、このREADMEと `manifest.json` が入っているフォルダーを選びます。
3. 普段使っているブラウザでPixivのページを通常どおり開きます。そのページを表示した状態で、拡張機能メニューから「Open Pixiv Downloader — 保存診断」をクリックします。診断用の別タブが開きます。
4. 「検証を開始」を押します。約30秒を目安に、元のPixivタブと診断タブを開いたまま待ちます。
5. 「レポートを保存」を押し、`pixiv-validation-report.json` を診断の依頼元へ共有できます。停止した場合も、そのレポートが原因の確認に使えます。

小説や画像の作品本体を保存するツールではありません。HTTP 401・403・429、リダイレクト、JSON以外の応答があれば、その時点で全体を停止します。再試行・CAPTCHA処理・アクセス制限の回避は行いません。現在のブラウザセッションを利用しますが、Cookieを読み出す権限は要求しません。

## 対象

| 種別（利用者申告） | 作品ID | 確認内容 |
|---|---|---|
| イラスト | 149564947 | 実際の種別、ページ数、原寸媒体の所在 |
| 漫画 | 130117333 | 全ページ数と順序。元URLの#1で1ページに限定しない |
| 小説 | 29476682 | 本文ハッシュ、記法数、表紙・挿絵の所在、シリーズ所属 |
| うごイラ | 151427872 | 素材ZIPの所在、フレーム名、順序、表示時間 |

対象以外の作者一覧・検索・ランキングは要求しません。外部サーバーへレポートを送信する機能はありません。利用者がローカルへ保存し、共有するか選べます。

## 現在の検証状況と限界

- Linux／Node.jsで模擬応答による8件の試験に合格。
- Linux／Chromiumの通常ページ上でも、同一オリジンの合成セッション、4作品のメタデータ収集、403での停止を確認。画面とJSONダウンロードはブラウザAPIを模擬して確認した。
- このクラウドのChromiumは管理者ポリシーで拡張の読込が禁止されており、拡張のインストール・起動自体は検証できていない。
- 実サイトとWindows／Edge／Chromeでの実行は未検証。
- 画像・ZIP本体の取得、デコード、ZIPのCRC、小説の表示一致はこの診断では確認しません。
- 小説の参照挿絵は最大20件、アップロード挿絵の一覧は最大50件。超過時は省略を明記します。
- 直列要求、既定3秒間隔、最大12要求、1応答8MiB、要求ごと20秒のタイムアウト。Pixivの許容値を確認した数値ではありません。
- activeTabとscriptingだけを要求し、利用者が拡張を起動したPixivタブで実行します。認証情報をファイルへ書き出しません。

## 開発用の再現

外部パッケージは不要です。Node.jsで `node --test collector.test.mjs` を実行します。模擬データを用い、実Pixivには接続しません。

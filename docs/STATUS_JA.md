# 検証状況

更新：2026年10月31日。元の比較は2026年10月30日に実施。

主実装をRust + Ratatuiへ移行した。Rustテスト25件、旧Pythonテスト49件、fmt・Clippy、両方向のアーカイブ互換性検査がLinuxで合格。Linuxの実ターミナルで、Rust版の起動、デモ保存、検査、ZIP出力、終了を確認した。PowerShell／Windows実機での検証は引き続き未実施。[移行記録](RUST_MIGRATION_JA.md)に検証範囲を記載する。

## 確認済み

- 採用したPythonコアの既存33テストと、4形式の合成CLI実演。
- 比較候補PxArchiveの16テストと、合成通信によるローカルHTTP保存ジョブ。
- 診断拡張のNode.jsテスト8件。本文の独立したSHA-256との一致、秘密値と本文の除外、401/403/429の全体停止、ID・ページ数・応答形式の検査。
- Linux Chromium 154.0.8037.57の通常ページで、実際のfetch・合成セッションを使った4作品8要求の診断と、403時の1要求停止。
- 診断画面はChrome API部分を模擬し、表示・JSON保存・内容の一致を確認。[ブラウザ記録](evidence/windows-probe-browser-results.json)に範囲を記載。

## 未確認・既知の不足

- Windows実機と、拡張のインストール・activeTabによる起動。このクラウドでは管理者ポリシーが拡張の読み込みを禁止し、設定は変更していない。
- 4形式の実サイト互換性、本人セッションでの取得、全小説記法の互換性。
- 更新検出・旧版保持は未実装。ZIP内部CRCの見逃しは旧Python版に残る。Rust版の新規保存時には全メンバー読み取りとCRC破損の拒否を確認した。媒体デコードによる検査は未実装。
- 画像・ZIP本体のデコードと完全性はメタデータ診断の対象外。
